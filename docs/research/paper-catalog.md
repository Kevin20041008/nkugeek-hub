# 论文目录维护规范

## 当前范围

首批 60 篇，覆盖 2013–2025 年首次发布的代表性工作：NLP 14、CV 14、
多模态 8、具身智能 14、强化学习 10。校订日期为 2026-09-28。
这是面向学习和复现选题的人工精选目录，不是系统性文献综述、最新论文榜或引用量排名。

组织方式参考 [Spinning Up: Key Papers in Deep RL](https://spinningup.openai.com/en/latest/spinningup/keypapers.html)。
NLP、CV、多模态和具身方向独立按论文原始来源扩充，未将 Spinning Up 描述为这些方向的来源。

## 数据与来源

- 数据：`src/data/papers.ts`。每条都有稳定 slug、完整标题、作者简写、首次预印本年份、arXiv ID、领域、标签和实践建议。
- 标题、作者、年份通过对应 arXiv 摘要页核对。数学符号 pi0 / pi0.5 在目录使用可搜索的 ASCII 转写。
- 原文按钮进入摘要和版本记录，PDF 按钮进入 PDF；不把摘要页误标成 PDF。
- 补充资源区分作者代码、作者项目页、补充材料与教学参考实现。资源可访问不等于已验证安装成功。
- 未核实的代码链接留空，不杜撰仓库地址，也不由缺少链接推断作者没有开源。
- `year` 不是会议年份。例如 BERT 记 2018、ResNet 记 2015、MAE 记 2021。
- DQN 条目明确对应 2013 年 Playing Atari 预印本，而非 2015 年 Nature 版本。

## 建议不是成绩

`difficulty`、`mode`、`goal`、`dataset`、`metrics` 和 `caution` 是社区编辑建议。
目录中所有条目当前都待认领，尚无社区实测结论。
不承诺特定显存容量即可运行，不把预训练权重推理、缩小训练或替代模型实验写成全量复现。
封闭模型、未公开数据、机器人硬件、数据许可和外部 API 成本必须说明。

旧版三个示例条目中的 SAM 分数、负责人、分享时间、实验日志与占位报告链接已撤下。
没有对应数据划分、提示协议与日志的分数不能继续作为社区实验事实展示。

## 新增或更新

1. 在原始论文页核对标题、作者和首次版本时间。检查 arXiv ID 与论文相符。
2. 选择一个主领域，用标签表达交叉方向；不要重复收录同一篇论文凑数量。
3. 编写自己的简短方法介绍，不复制整段摘要。给出一个明确的最小实验目标。
4. 写明数据与指标协议的注意事项。代码必须指向可核验的作者资源或标为参考实现。
5. 保持已有 slug 不变，以免破坏公开链接；必要时更新阅读路线。
6. 运行 lint、build、test:smoke。测试覆盖唯一性、路由、筛选、分页与来源。

## 发起复现

先搜索现有 Issue，再用详情页预填表单提交实验范围和资源预算。
不要批量自动创建 60 个空 Issue。真正开始实验后，在 Issue / PR 提供：

- 数据集版本、许可、划分、预处理与泄漏检查。
- 代码 commit、模型权重、硬件、依赖锁定、随机种子和运行命令。
- 要对齐的原文表格、指标定义和与原始设置的差异。
- 实际实验日志、各次运行结果、失败案例、统计口径与复现报告。

后续如增加进度数据，应另建可核验的实验记录来源；不能仅因点击按钮或提交计划就将状态改为“复现成功”。
