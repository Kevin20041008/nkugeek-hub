# NKUGeek Hub Product Roadmap

## Positioning

NKUGeek Hub is an open learning and engineering community for Nankai University students. Its core loop is:

`learning path -> runnable project -> GitHub Issue -> Pull Request -> reusable outcome`

The website is a public entry point. GitHub repositories are the source of truth for code, documentation, discussion, tasks, and contribution history.

## First Release

- Public learning paths with staged tasks and outputs
- Open project directory with repository and Issue links
- Open challenge list with difficulty, effort, and acceptance criteria
- Contribution guide for Issues, branches, tests, and Pull Requests
- Paper reproduction workflow and reports
- Engineering asset center for code, PCB, CAD, and releases
- Public articles and event records

The first release does not require website accounts, project applications, article moderation, or an admin dashboard.

## Phases

1. Open entry: learning paths, open projects, task templates, contribution guide.
2. Practice loop: chapter exercises, Issue claiming, automated tests, Pull Requests.
3. Engineering assets: code Diff, PCB preview, CAD conversion, release archive.
4. Research reproduction: datasets, environments, experiment logs, metric comparison, reports.
5. Community governance: Maintainer and Mentor roles, project incubation, release roadmaps.
6. Intelligent tooling: source navigation, experiment summaries, task decomposition, knowledge retrieval.

## Out Of Scope For The First Release

- Website login and registration
- Internal project application workflow
- Article review queues
- Instant chat and video meetings
- Points or virtual goods
- Mobile applications
- Microservices and complex recommendation systems
