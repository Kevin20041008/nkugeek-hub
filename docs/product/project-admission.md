# Project Incubator

## 状态

- Ideas：缺少负责人、仓库、下一里程碑、开放任务或预计投入的想法。
- Recruiting：材料完整，明确公开招募任务。
- Building：团队正在围绕已确认里程碑建设。
- Released：已发布可验证产出，仍有维护任务。
- Archived：不再活跃；保留历史与归档原因，不继续招募。

主列表默认只显示材料完整的 Recruiting / Building / Released。
状态以 src/data/community.ts 为来源，effectiveProjectState 强制检查收录条件。
没有开放任务的项目不会被当作活跃协作项目；Archived 不伪装成 Ideas。

## 提交

通过项目页预填 Issue 提案，提供负责人公开账号、真实 Repo、当前状态、
Next milestone、开放 Issue 链接、预计时间投入、前置 Learn 路径与关联论文。
估时是范围沟通工具，不是向贡献者的保证。

每个里程碑应包含可检查交付、验证命令或评估协议。完成后附来源更新 Showcase。
