# Community Structure

## Navigation

Learn / Build / Research / Community / Showcase 为仅有的五个主导航。
任务、论文、活动、档案与工程阅览器在各栏目内部导航。
移动端菜单具备名称、展开状态与返回正文入口。

## Contribution Loop

- Learn 的完整 Python 课程连接真实 Issue 和 Hub 项目。
- Foundations 是官方资源导学，不冒充站内完整实验课程。
- PyTorch 导学连接 ResNet；ViT 导学连接 DINO。
- 项目详情连接前置知识、相关论文、任务与成果。
- 科研详情连接基础学习、项目提案、任务中心与成果提交。
- Showcase 返回项目与学习，形成后续贡献入口。

## Shared Grammar

标题、简短说明、文字状态、难度或类别、技术栈与来源、主动作。
ProjectCard / TaskCard / ShowcaseCard 共用结构和 Status。
状态同时使用文字与有对比度的颜色。无结果提供空状态、重置或提交入口。
过滤器使用原生 select，搜索具备可访问名称；图标按钮有名称和 title。

## Truthfulness

首页不显示社区规模统计。Community Activity 只使用带来源的 GitHub 快照。
未发布任务标为提案，动作是“讨论提案”；只有真实 Issue 提供认领入口。
外部成果不冒充社区项目；成员、活动、复现指标不使用占位数据。
